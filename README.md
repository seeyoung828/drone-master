# WiFi 기반 노지 분산 IoT 센서 데이터 수집 프로젝트

## 프로젝트 소개
드론에 탑재된 Raspberry Pi를 WiFi AP로 활용하여,
노지 환경에 분산된 IoT 센서의 이미지 및 로그 데이터를 수집하는 프로젝트입니다.

## 프로젝트 목적
- 드론을 이동형 AP로 활용
- 센서 노드의 데이터 수집
- 공정한 데이터 전송 제어 구현
- 재접속 및 이어받기 구조 설계

## 팀원
- 팀장: 장시영
- 팀원1: 이민형
- 팀원2: 서정우
- 팀원3: 김성진
- 팀원4: 오현승

## 사용 장비
- Raspberry Pi 4 Model B (4GB)
- microSD 카드
- 배터리
- ESP32 / ESP32-CAM
- 센서 및 카메라 모듈




본 저장소는 프로젝트 진행 기록, 회의록, 코드 및 문서를 함께 관리하기 위한 공간입니다.
