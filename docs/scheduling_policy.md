# 🛰️ 드론 기반 데이터 수집 스케줄링 정책 (v2.1)

---

## 1. 문서 목적

본 문서는 드론(Raspberry Pi AP)이 이동하며 고정된 여러 센서 노드(ESP32-CAM)로부터 이미지 데이터를 효율적으로 수집하기 위한 **하이브리드 스케줄링 정책**을 정의한다.

특히 다음 요소를 동시에 고려한다:

- 신호 세기 (RSSI)
- 데이터 시급성
- 미접촉 시간 (Aging)

이를 통해 특정 노드의 방치를 방지하고 전체 수집 효율을 극대화하는 것을 목표로 한다.

---

## 2. 문제 정의 및 설계 목표

- **제한된 접촉 시간**  
  드론 이동으로 인해 통신 가능 시간이 매우 짧음

- **공정성 및 기아 방지**  
  신호가 약한 노드도 일정 시간 후 우선순위 상승

- **세션 연속성**  
  재접촉 시 이전 전송 지점부터 즉시 재개

---

## 3. 타겟 선택 정책 (Selection Policy)

드론은 BEACON 정보를 기반으로 다음 전송 권한(GRANT)을 부여할 노드를 결정한다.

가장 높은 **스케줄링 점수(Score)**를 가진 노드를 선택한다.

### 3.1 스케줄링 점수 공식

$$
Score = (w_1 \times NormRSSI) + (w_2 \times NormRemaining) + (w_3 \times NormAging)
$$

#### 구성 요소

- **NormRSSI (신호 품질)**
  - RSSI 값 (-100 ~ -30 dBm)을 0 ~ 1로 정규화
  - 신호가 좋을수록 높은 점수

- **NormRemaining (데이터 시급성)**
  - 남은 청크 비율을 0 ~ 1로 정규화
  - 데이터가 많이 남을수록 높은 점수

- **NormAging (미접촉 시간)**
  - 계산식:
    $$
    T_{now} - T_{last\_contact}
    $$
  - 일정 시간 이상 미접촉 시 가산점 부여

---

### 3.2 권장 가중치

| 항목              | 값  |
| ----------------- | --- |
| $w_1$ (RSSI)      | 0.3 |
| $w_2$ (Remaining) | 0.4 |
| $w_3$ (Aging)     | 0.3 |

---

## 4. 하이브리드 슬롯 종료 정책 (Termination Policy)

다음 조건 중 하나라도 만족하면 슬롯 종료:

- **시간 제한 ($T$)**
  - 5초 초과

- **청크 제한 ($N$)**
  - 기본 20개 초과

- **신호 품질 저하**
  - RSSI ≤ -85 dBm

- **전송 완료**
  - 모든 데이터 수신 완료

---

## 5. 기회주의적 동적 파라미터 (Opportunistic Scheduling)

| 환경      | 조건                 | 정책     |
| --------- | -------------------- | -------- |
| 최적 환경 | RSSI > -50 dBm       | $N = 40$ |
| 일반 환경 | -50 ≥ RSSI > -75 dBm | $N = 20$ |
| 한계 환경 | RSSI ≤ -75 dBm       | $N = 10$ |

---

## 6. 통신 규격 및 데이터 무결성

### 6.1 패킷 구조

Type | S_ID | Total | Idx | RSSI | [Payload]

- 파이프(`|`) 구분자 기반

---

### 6.2 신뢰성 및 무결성

- **Block ACK**
  - GRANT의 인덱스로 이전 수신 확인

- **에러 복구**
  - 응답 없을 시 최대 3회 재시도

- **최종 검증**
  - 전체 데이터에 대해 CRC32 수행

---

## 7. 상태 정의

| 상태       | 설명                         |
| ---------- | ---------------------------- |
| COLLECTING | 데이터 전송 중               |
| PAUSED     | 슬롯 종료로 중단 (재개 가능) |
| COMPLETED  | 수집 및 검증 완료            |
| TIMEOUT    | 응답 없음으로 제외           |
