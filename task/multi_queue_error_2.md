# 📋 다중 이미지 큐 및 세션 전환 오류 분석 보고서 (Analysis Report 2)

**분석 대상:** `drone_test_log.txt` (v2.6 기반 라즈베리파이 테스트 결과)
**핵심 문제:** 세션 전환 시 발생하는 `SESSION_MISMATCH` -> `COMPLETE` -> `CHECKSUM_FAIL` 무한 루프

---

## 1. 에러 현상 상세 분석

### 1.1 연쇄 반응 시퀀스 (The Chain Reaction)
로그에서 반복적으로 나타나는 패턴을 시간 순으로 재구성하면 다음과 같습니다.

1.  **마스터:** `Sensor_01`의 비콘을 수신했으나, 메모리 상의 이전 `Data_ID`와 달라 세션 전환으로 감지하고 **`SESSION_MISMATCH`** 에러를 보냄.
2.  **슬레이브:** 에러를 수신하고 현재 전송 루프(`Inner Loop`)를 `break`로 탈출함.
3.  **슬레이브 (버그 발생):** 루프를 탈출한 직후, 전송이 완료되지 않았음에도 불구하고 코드 구조상 **`send_complete()`**를 무조건 호출함.
4.  **마스터:** 데이터를 하나도 받지 못한 상태(혹은 일부만 받은 상태)에서 `COMPLETE` 패킷을 수신하고 검증(`verify_and_finalize`)을 시도함.
5.  **마스터:** 임시 파일이 없거나(`FileNotFoundError`) 조각 수가 부족하여 **`CHECKSUM_FAIL`**을 발생시키고 슬레이브에게 알림.
6.  **슬레이브:** 전송 실패로 간주하고 다음 이미지로 넘어가거나 재시도하면서 다시 비콘을 보냄 -> 1번으로 돌아가 무한 반복.

### 1.2 주요 원인 분석 (Root Causes)

#### A. 슬레이브 루프 탈출 조건의 모호성 (`sensor_node.py`)
- 현재 코드 구조는 전송 루프가 정상적으로 끝났을 때와 에러(`TIMEOUT`, `SESSION_MISMATCH`)로 인해 중단되었을 때를 구분하지 않고 항상 `send_complete()`를 실행합니다. 이로 인해 마스터에게 잘못된 완료 신호를 보내 시스템 혼란을 초래합니다.

#### B. 마스터의 세션 전환 정책 미흡 (`drone_master.py`)
- 다중 이미지 큐 환경에서는 노드가 한 이미지를 마치고(혹은 실패하고) 다음 이미지로 넘어가는 것이 정상적인 흐름일 수 있습니다. 하지만 마스터는 `sensors_mem`에 이전 정보가 남아있으면 이를 '비정상 충돌'로 간주하여 `SESSION_MISMATCH`를 보냅니다.

#### C. 검증 로직의 가드 코드 부재 (`db_manager.py`)
- `verify_and_finalize`가 호출될 때, 수집된 조각이 0개이거나 파일이 존재하지 않는 경우에 대한 사전 체크가 부족하여 `FileNotFoundError` 크래시나 불필요한 로그가 생성됩니다.

---

## 2. 해결 방안 (Proposed Solutions)

### 2.1 슬레이브: 전송 완료 조건 강화
- **수정 사항:** `Inner Loop`를 탈출할 때 `is_finished`와 같은 플래그를 사용하여, 마스터로부터 "모든 데이터 수신 완료(Target_Idx >= Total)" 신호를 받았을 때만 `send_complete()`를 호출하도록 수정합니다.
- **기대 효과:** 불완전한 상태에서의 `COMPLETE` 보고를 차단하여 마스터의 검증 리소스 낭비를 방지합니다.

### 2.2 마스터: 유연한 세션 전환 허용
- **수정 사항:** `BEACON` 수신 시 `Data_ID`가 바뀌더라도 무조건 에러를 보내는 대신, 이전 세션의 상태가 `COLLECTING`이 아니거나 일정 시간이 지났다면 자연스럽게 새 세션으로 업데이트하도록 로직을 완화합니다.
- **기대 효과:** 다중 이미지 전송 시 이미지 간 전환이 매끄럽게 이루어집니다.

### 2.3 DB 매니저: 검증 전 방어 로직 추가
- **수정 사항:** `verify_and_finalize` 시작 부분에서 `received_count > 0` 여부와 물리 파일 존재 여부를 먼저 확인하고, 조건 미달 시 즉시 실패를 반환하도록 개선합니다.
