드론이 AP로 동작하며 센서가 접속하여 데이터를 업로드하되, 드론이 센서별 전송을 중단한 후, 다른 센서와의 접속을 허가하여 공정하게 전송 자원을 분배하는 기술

즉 1, 2의 기능이 아직 구현되지 않았고 project_progress.md 파일에 반영되지 않았다고 판단된다.

1. 특정 센서의 전송이 길어질 경우, 드론 AP가 해당 센서의 전송을 중단하고 다른 센서의 데이터를 수집하는 기능

2. 드론 AP로부터 전송 중단 명령을 받은 센서가, 경로를 따라 순회하고 돌아온 드론에 다시 접속하는 기능

또한 

드론 AP가 접속 센서들의 전송 시간을 모니터링하여 일정 시간 이상 전송 시 강제 세션 종료 명령 전송하는 기능을 추가하여 

결론적으로 전체 센서 데이터를 균등하게 수집하고 배터리 제약 하에서 최대로 수집해야한다.

이러한 기능들이 지금 project_progress.md 파일에 명확하게 반영되었는지 판단하고 없다면 향후 추진 계획에 추가해라.
